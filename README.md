# Gemini-AI-Chatbot-using-LangChain
**Gemini AI Chatbot using LangChain is a Python-based conversational chatbot that integrates Google Gemini 2.5 Flash-Lite with the LangChain framework. It uses the Gemini API to understand and generate natural-language responses to user queries. The chatbot runs in a continuous command-line loop, allowing users to interact with the AI in real time and exit the conversation by typing exit.

Technologies Used:-

Python
Google Gemini API
Gemini 2.5 Flash-Lite
LangChain
LangChain Google GenAI
HumanMessage
Command-Line Interface (CLI)
